# 日常 · 饮食与训练

一个轻量、离线优先的个人饮食与训练记录网页。应用只监听本机地址，用户数据保存在本机，不会上传。

## 运行

需要安装 Node.js 和 Windows PowerShell。在 Windows 上双击 `启动饮食训练记录.bat`，浏览器会打开本地网页。也可以在项目目录运行 `node app.js`，然后访问 <http://127.0.0.1:38472/>。

数据保存在 `data.json`，CSV 可从网页右上角导出。不要把个人 `data.json` 提交到公开仓库。

## 功能

- 按日期记录饮食；输入常见食物和份量后，本地自动估算热量与蛋白质，可附餐食照片路径
- 记录训练项目、动作、组数、次数、重量和时长
- 记录体重、睡眠和状态备注
- 自设热量与蛋白质目标，查看近七天摄入趋势
- 导出 CSV

营养估算使用本机食物成分数据；未识别条目不会纳入合计，份量不明确时不会套用默认份量。数据可手动修正。照片只记录本机路径。

## 本机食物数据库

饮食计算读取工作簿中的「能量和食物一般营养成分」表，按每 100g 的能量和蛋白质数据乘以输入重量计算。每种食物需单独输入一行并写明克数，匹配项可以在预览里切换；没有重量时不会套用默认份量。

数据库索引 `foods.local.json` 和个人记录 `data.json` 只保存在本机，并已加入 Git 忽略规则。公开仓库只提供程序代码，不包含营养表数据。

### 从 GitHub 下载后的首次设置（Windows）

1. 下载并解压项目，安装 Node.js 和 Microsoft Excel。
2. 准备自己有权使用的 `.xls` 或 `.xlsx` 食物成分表，其中需包含「能量和食物一般营养成分」工作表。
3. 在项目文件夹打开 PowerShell，运行下面的命令；将路径替换成表格的实际位置：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\导入食物数据库.ps1 -SourcePath "C:\数据\中国食物成分表.xls"
   ```

4. 按提示确认导入，再双击 `启动饮食训练记录.bat`。

没有食物成分表时，程序仍可启动和记录饮食，但数据库搜索与自动营养计算不可用。完整食物表不会随项目公开下载。
