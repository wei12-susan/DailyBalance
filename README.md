# 日常 · 饮食与训练

一个轻量、离线优先的个人饮食与训练记录网页。应用只监听本机地址，用户数据保存在本机，不会上传。

## 运行

需要安装 Node.js 和 Windows PowerShell。在 Windows 上双击 `启动饮食训练记录.bat`，浏览器会打开本地网页。也可以在项目目录运行 `node app.js`，然后访问 <http://127.0.0.1:38471/>。

数据保存在 `data.json`，CSV 可从网页右上角导出。不要把个人 `data.json` 提交到公开仓库。

## 功能

- 按日期记录饮食、热量和蛋白质，可附餐食照片路径
- 记录训练项目、动作、组数、次数、重量和时长
- 记录体重、睡眠和状态备注
- 自设热量与蛋白质目标，查看近七天摄入趋势
- 导出 CSV

热量与营养数据需要自行估算或修正；照片不能准确推算食物份量。照片只记录本机路径。
