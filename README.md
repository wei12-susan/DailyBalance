# 日常 · 饮食与训练

一个轻量、离线优先的个人饮食与训练记录网页，适合记录每天吃了什么、训练了什么，以及身体状态的变化。应用只在本机运行，个人数据保存在自己的电脑上。

## 快速开始

1. 下载并解压本项目。
2. 安装 [Node.js](https://nodejs.org/)。
3. 双击 `启动饮食训练记录.bat`，浏览器会打开本地网页。
4. 如果网页没有自动打开，可以手动访问 <http://127.0.0.1:38472/>。

数据保存在项目目录的 `data.json` 中。网页右上角可以导出 CSV。请勿将包含个人记录的文件公开上传。

## 功能

- 按日期记录饮食、食物份量和餐食照片路径
- 根据输入的食物重量，查询本机食物数据库并计算热量与蛋白质
- 记录训练动作、组数、次数、重量和时长
- 记录身高、体重、睡眠和状态备注，并根据身高体重计算 BMI
- 设置每日热量和蛋白质目标，查看近期摄入趋势
- 导出 CSV

## 食物热量计算

计算使用食物数据库中每 100 克的营养数值，结合输入的实际克数换算。请每种食物单独写一行并标明重量，例如：`米饭 200g`。匹配项可以在预览中切换；未识别的食物不会计入总量，缺少重量时也不会套用默认份量。计算结果可以手动修正。

公开仓库不包含食物成分表。要启用本地食物搜索和自动营养计算，请按以下步骤准备自己的数据：

1. 安装 Microsoft Excel。
2. 准备自己有权使用的 `.xls` 或 `.xlsx` 食物成分表，且其中包含「能量和食物一般营养成分」工作表。
3. 在项目文件夹打开 PowerShell，运行下方命令，并将路径替换为表格的实际位置：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\导入食物数据库.ps1 -SourcePath "C:\数据\中国食物成分表.xls"
   ```

4. 按提示确认导入，然后双击 `启动饮食训练记录.bat`。

没有导入食物表时，网页仍可用于饮食和训练记录，但食物搜索与自动营养计算不可用。导入后生成的 `foods.local.json` 只保存在本机，不会上传。

## 隐私与数据

- `data.json` 保存饮食、训练和身体状态等个人记录。
- `foods.local.json` 是从你自己的食物成分表生成的本地索引。
- 照片仅保存本机路径；程序不会上传照片或上述数据。
- 两个 JSON 数据文件均已加入 Git 忽略规则，请勿手动添加到公开仓库。
